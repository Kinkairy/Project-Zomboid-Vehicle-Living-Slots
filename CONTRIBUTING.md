# Contributing

Please open an issue before making a substantial vehicle-script, persistence,
fluid, power, appliance, or multiplayer change. Preserve original Project
Zomboid and KI5 behavior, keep multiplayer state authoritative on the server,
and describe how each changed logic path was verified.

Do not commit credentials, server addresses, private logs, local Workshop
publisher files, generated caches, test harnesses, copied third-party assets,
or unrelated Mods.
