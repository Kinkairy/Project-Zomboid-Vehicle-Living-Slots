# Mobile Living 3.12

3.12：重构共用安装、供电、供水与设备判断框架；按原版家具尺寸划分生活和顶部空间，扩展家具及电器支持；修复车顶灯闪烁与 F700 油桶操作，降低行李架碰撞损耗。

3.12: Refactored the shared framework for installation, power, water supply and equipment checks; classified living and overhead spaces using vanilla furniture dimensions and expanded furniture and appliance support; fixed roof-light flicker and F700 fuel-can operations, and reduced roof-rack collision wear.

## Compatibility / 兼容性

旧档中生活空间的小型设备保留原位；拆下重装遵循新的顶部空间规则。如发现旧档兼容问题，欢迎反馈。

Existing small appliances in living spaces remain usable; reinstallations follow the new overhead-space rules. Please report compatibility issues with existing saves.
