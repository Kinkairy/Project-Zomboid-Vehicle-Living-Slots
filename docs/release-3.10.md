# Mobile Living 3.10

Adds the optional VehicleLivingSlotsKI5F700 module for the KI5 F700 Bank and SWAT vans, and B700 School, Prison and Military Buses. Install the original KI5 vehicle pack and damnlib and enable the adapter alongside Mobile Living.

- Bank retains seven living positions; SWAT and the three Buses can exchange their original rear seats for living equipment. Installed seats use each vehicle's driver-seat item.
- Common water, power, appliances, roof fuel and generator services use the core implementation. Bus variants provide four water tanks and two auxiliary batteries.
- Corrected seat-map numbering, layout, equipment labels and door-icon hit regions. Original passenger positions and physical entry/exit points are preserved.
- Refined Bus mechanics icon positions, equal tank sizes, battery positions and native rear armor placement. Corrected Bank, SWAT and Camper connector lines. F700 list ordering applies only to F700 vehicles.
- Roof tent positions accept all seven native packed tents and return the original item on removal.

Validation: exact 268-file runtime manifest; Lua syntax and focused source regressions; native texture, hit-region and connector geometry checks. In-game acceptance remains separate from source validation.

The previously accepted RC3.9 recovery baseline is retained.
