# Mobile Living 3.11

3.11: Added deployable rooftop solar panels with auxiliary-battery charging, direct-material installation and a sandbox switch; panels retract on vehicle movement. Improved roof-rack lighting and fixed native mechanics tool detection, multiplayer action arguments and mechanics-cheat compatibility.

3.11：新增可展开的车顶太阳能板，为车辆辅助电池充电，支持直接使用材料安装及沙盒开关，车辆移动时自动收回；改善行李架受光，修复原版维修工具识别、多人动作参数及机械作弊兼容。

3.11：新增可展開的車頂太陽能板，為車輛輔助電池充電，支援直接使用材料安裝及沙盒開關，車輛移動時自動收回；改善行李架受光，修復原版維修工具識別、多人動作參數及機械作弊相容。

Existing storage, appliances and KI5 adapter behavior are retained. The independent Bicycle tailgate adapter is not part of this release. F700 retains its own version 0.1.2.

Validation: native B42.21.0 Lua loaders, constructor argument serialization, material/tool and sandbox regression checks passed. The owner accepted the joint test on 2026-10-02 at 18:17:40 UTC. This acceptance is a user statement; no direct multiplayer Action trace was captured for that window.
