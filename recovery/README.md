# Recovery packages

`vehicle-living-slots-v3.8.0-public-recovery.zip` is the current public recovery
package. It contains the complete repository `workshop/` payload at the RC3.8
publication baseline; its per-file hashes are listed in the matching
`.manifest.sha256` file.

The `v3.7.0` archive is retained as historical recovery material and is not the
current release. Before restoring, verify the archive hash and the target
Project Zomboid Build 42.20 installation. Runtime, save, and multiplayer
acceptance checks remain separate from archive integrity verification.
